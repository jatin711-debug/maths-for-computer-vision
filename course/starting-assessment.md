# Starting assessment

Spend about 25 minutes. No searching; "not sure" is useful. Show reasoning. Questions 9-11 preview later modules, so unfamiliarity is expected.

1. Solve 3x+5=20. Show one intermediate step.

2. For f(x)=2x+1, compute f(3). What is the slope of its graph?

3. Simplify ln(e^2). What input values are allowed for ln(x) over the real numbers?

4. Find the mean of pixel values 20, 60, 100, 140.

5. If I=[[20,60],[100,140]], compute 0.5I+10 entry by entry.

6. For vectors u=[1,2] and v=[3,4], compute their dot product.

7. If A is 3x2 and x is 2x1, what is the shape of Ax? Can xA be multiplied in this order?

8. Solve x+y=5 and x-y=1.

9. Differentiate x^2. Then differentiate (2x+1)^2.

10. For f(x,y)=x^2+3xy, find the two partial derivatives.

11. Given P(A)=0.2, P(B given A)=0.8 and P(B given not A)=0.1, find P(A given B).

12. Optional Python: create a 2x2 NumPy array and compute its mean. Explain the difference between * and @ for arrays.
